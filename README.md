# Bản chạy trên điện thoại (không cần máy chủ)

Một web app cài được lên màn hình chính (PWA). Mọi thứ chạy ngay trên điện thoại, gọi thẳng Gemini API miễn phí bằng khóa của bạn. Khóa chỉ lưu trong trình duyệt của máy.

## Đưa lên mạng miễn phí (bắt buộc dùng https để cài được)
Chọn một trong các cách, đều miễn phí:
- Netlify Drop: vào app.netlify.com/drop, kéo thả cả thư mục này.
- Cloudflare Pages hoặc GitHub Pages: tải thư mục lên, bật Pages.
Sau đó mở đường link trên điện thoại.

## Cài lên màn hình chính
- iPhone (Safari): Chia sẻ → Thêm vào MH chính.
- Android (Chrome): Menu ⋮ → Cài đặt ứng dụng / Thêm vào màn hình chính.

## Lần đầu
Bấm ⚙️, dán khóa Gemini (lấy tại aistudio.google.com/apikey, miễn phí, không cần thẻ), bấm Lưu.

## Lưu ý
- Không chia sẻ link kèm khóa; mỗi người dùng khóa của riêng mình.
- Bộ nhớ đệm trong máy: tin đăng 4 giờ, giá đất 7 ngày.
- Hạn mức miễn phí của Google có thể thay đổi hoặc báo hết tạm thời.

## Bảng giá đất của bạn (nút 📄)
- Nhập số văn bản (VD 12/2025/NQ-HĐND): app tra theo đúng văn bản đó. Có văn bản mới thì nhập số mới và lưu.
- Tải file CSV/JSON (đọc trực tiếp) hoặc PDF/ảnh phụ lục (AI trích xuất, tối đa 4 MB, cần kiểm tra lại). Tải file mới sẽ thay thế bảng cũ; tích "Thêm vào bảng hiện có" để nối thêm.
- Khi tìm đúng tên đường có trong bảng, app lấy giá từ bảng của bạn trước; không có thì mới tìm trên web.
- Đơn vị giá: văn bản chính thức thường tính nghìn đồng/m², hãy chọn đúng đơn vị trước khi tải.
